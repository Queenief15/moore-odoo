Installer le favori « Devoldère → Odoo »

Pneus Devoldère — envoyer les ventes et la caisse de TyreStream dans Odoo

À faire une seule fois

  1. Ouvre cette page dans Google Chrome, Microsoft Edge ou Firefox.
  2. Fais apparaître la barre des favoris : appuie en même temps sur Ctrl + Maj + B.
    Une barre apparaît sous l'adresse du site (dans Firefox, elle s'appelle « barre personnelle »). Si elle était déjà là, elle disparaît : appuie encore une fois.
  3. Avec la souris, attrape le bouton bleu ci-dessous et lâche-le dans la barre des favoris :
    Devoldère → Odoo
  4. C'est fini : le bouton « Devoldère → Odoo » est maintenant dans ta barre des favoris.

Préparation du favori…

Ne clique pas sur le bouton bleu de cette page : il faut le glisser. Il ne fonctionne que dans l'Odoo de Pneus Devoldère.

Si le glisser ne marche pas :
puis clic droit dans la barre des favoris › « Ajouter une page… » (Chrome), « Ajouter cette page aux favoris » (Edge) ou « Ajouter un marque-page… » (Firefox), nom « Devoldère → Odoo », et colle dans la case de l'adresse (URL).

Mises à jour

Rien à faire : à chaque clic, le favori charge la dernière version de l'outil publiée sur cette page. Le favori déjà installé reste valable.
